# Vakio Kiv Smart (Motorized Damper)

Интеграция для [Home Assistant](https://www.home-assistant.io/), предназначенная для управления приточными клапанами **Vakio Kiv Smart** с **моторизованной заслонкой** через локальный MQTT.

---

## 📌 Отличия от оригинальной интеграции

Оригинальная интеграция разрабатывалась для других моделей устройств Vakio (содержащих вентилятор или использующих устаревшие сущности `select`/`fan`). В модели **Vakio Kiv Smart** вентилятора нет — устройство представляет собой приточный клапан с шаговым приводом заслонки (4 рабочих положения + закрыто).

### Основные улучшения этого форка:
1. **Правильный тип сущности — `Cover` (заслонка)**:
   - Заслонка представлена сущностью `cover` с поддержкой уровней открытия: `0%` (закрыто / выключено), `25%`, `50%`, `75%` и `100%`.
   - **Почему именно базовый `cover`, а не `device_class: damper`?** В Home Assistant класс устройства `damper` исключает заслонку из встроенных дашбордов и группировок категории «Климат» (Climate) (см. проблему фронтенда [home-assistant/frontend#53027](https://github.com/home-assistant/frontend/issues/53027)). Использование базового `cover` позволяет сохранить удобное отображение и предоставляет прямой слайдер степени открытия (0–100%) на карточке без необходимости переходить во вспомогательные меню.
   - Идеально интегрируется со слайдерами заслонок в интерфейсе Lovelace и голосовыми ассистентами.
2. **Встроенный MQTT Home Assistant**:
   - Работает напрямую через официальный компонент `homeassistant.components.mqtt`.
   - Не создаёт сторонних фоновых подключений через `paho-mqtt`, не требует повторного ввода логина/пароля брокера.
3. **Автоматическое восстановление положения при перезагрузке прибора**:
   - Прошивка Vakio Kiv при включении питания сбрасывает положение заслонки на заводское 2 (50%).
   - Интеграция отслеживает события старта прибора (`workmode: manual`) и мгновенно восстанавливает выбранное пользователем положение без задержек.
4. **Устранение лишних сбросов питания**:
   - При смене положений заслонки команды включения (`state: on`) отправляются только если прибор был выключен, предотвращая повторную калибровку привода при каждом переключении.
5. **Поддержка долгосрочной статистики (Long-Term Statistics / LTS)**:
   - Сенсоры температуры и влажности имеют класс `SensorStateClass.MEASUREMENT`, что позволяет сохранять долгосрочную статистику в Home Assistant и строить графики за недели и месяцы.
6. **Сохранение состояния (`RestoreEntity`)**:
   - При перезагрузке сервера Home Assistant положение заслонки и показания датчиков восстанавливаются из кэша до получения первых MQTT-сообщений.
7. **Группировка в единое устройство**:
   - Все сущности (заслонка, температура, влажность) объединены под одним устройством **Vakio Kiv** с поддержкой современных стандартов именования (`has_entity_name`).

## 🚀 Установка

### Способ 1: Через HACS (рекомендуется)
1. Откройте **HACS** → **Интеграции** (Integrations).
2. Нажмите меню с тремя точками в правом верхнем углу → **Пользовательские репозитории** (Custom repositories).
3. Добавьте URL: `https://github.com/Nyaaa/vakio_kiv` с типом **Интеграция** (Integration).
4. Найдите **Vakio Kiv Smart** в поиске HACS и нажмите **Загрузить**.
5. Перезагрузите Home Assistant.

### Способ 2: Вручную
1. Скопируйте папку `custom_components/vakio_kiv` в директорию `<config_dir>/custom_components/vakio_kiv` вашего Home Assistant.
2. Перезагрузите Home Assistant.

## ⚙️ Настройка

### 1. Подключение прибора к вашему MQTT-брокеру
В приложении или веб-интерфейсе настройки Vakio укажите:
* **MQTT Server**: IP-адрес сервера Home Assistant (или вашего брокера Mosquitto).
* **MQTT Port**: `1883` (по умолчанию).
* **Логин / Пароль**: Укажите данные пользователя Home Assistant, имеющего доступ к брокеру (если настроена авторизация).
* **Топик (префикс)**: Задайте уникальный топик (например, `vakio-smart-kitchen`).

### 2. Добавление интеграции в Home Assistant
1. Перейдите в **Настройки** → **Устройства и службы**.
2. Нажмите **Добавить интеграцию** и найдите **Vakio Kiv Smart**.
3. Введите топик прибора, указанный на предыдущем шаге (например, `vakio-smart-kitchen`).
4. Нажмите **Отправить**. Все сущности устройства автоматически появятся в системе.

## 📊 Доступные сущности

| Сущность | Тип | Описание |
|---|---|---|
| `cover.vakio_kiv_vent_damper` | Cover | Моторизованная заслонка (0%, 25%, 50%, 75%, 100%) |
| `sensor.vakio_kiv_temperature` | Sensor | Температура воздуха (°C) с поддержкой LTS |
| `sensor.vakio_kiv_humidity` | Sensor | Относительная влажность (%) с поддержкой LTS |

## 🛠️ Возможные проблемы и их решение

### ❓ Температура или влажность отображаются как "Недоступно" / "Неизвестно"
* **Аппаратная особенность Vakio**: Некоторые ревизии прошивки Vakio при сбое сети перестают публиковать топики `+/temp` и `+/hud`. 
* **Решение**: Обесточьте прибор физически из розетки на 10 секунд и включите обратно. После холодной перезагрузки устройство возобновляет отправку телеметрии датчиков.

### ❓ Изменения в коде не применяются после перезагрузки интеграции
* Home Assistant кэширует модули Python (`sys.modules`). При обновлении файлов кастомной интеграции требуется **полная перезагрузка Home Assistant** (**Инструменты разработчика** → **Перезапуск**).
